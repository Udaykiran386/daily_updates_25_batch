# Today's update: I learned data structures concept in python Data structures in Python are used to store, organize, access, and manage multiple values efficiently.
Python has four main built-in data structures:
1. List []
Stores multiple values, allows duplicates, and is mutable (changeable).
Example: numbers = [10, 20, 30]
2. Tuple ()
Stores multiple values, allows duplicates, and is immutable (cannot be changed after creation).
Example: colors = ("red", "blue", "red")
3. Set {}
Stores unique values and does not guarantee a fixed iteration order.
Example: numbers = {10, 20, 30}
4. Dictionary {key: value}
Stores data as key-value pairs. Keys must be unique.
Example: student = {"name": "Ravi", "age": 22}

# Today's update: I learned  window functions in SQL perform a calculation across a set of related rows without combining them into a single row. Unlike GROUP BY, it keeps each 
individual row in the result, Window functions are commonly used for ranking, running totals, averages, and comparing rows.

# some of the concepts in window functions RANK(), DENSE_RANK(), ROW_NUMBER(), NTILE(), LEAD(), LAG(), OVER(), SUM() understand the concepts how its work practiced different ways.

# RANK(): Gives ties the same rank and skips the next rank.
  DENSE_RANK(): Gives ties the same rank without skipping ranks.
  ROW_NUMBER(): Assigns a unique number to every row.
  NTILE(): window function that divides rows into a specified number of approximately equal groups (buckets) and assigns each row a bucket number.
  LEAD():  window function that fetches a value from the next row without using a self-join.
  LAG(): window function that retrieves a value from the previous row.
  OVER(): defines the window of rows that a window function uses to perform its calculation.

# Practiced joins s used to combine data from two or more tables based on a related column between them,
types of joins:
INNER JOIN : Returns only the rows where the joining column has a matching value in both tables.
LEFT JOIN: Returns all rows from the left table and only the matching rows from the right table. If there is no match, NULL is returned.
RIGHT JOIN: Returns all rows from the right table and only the matching rows from the left table. If there is no match, NULL is returned.
FULL JOIN: Returns all rows from both tables. Matching rows are combined, while non-matching rows contain NULL.
